# Clear to Ship — concept

## Build WITH Bob IDE (not a plugin for it)
The product is a **developer workflow tool**. Bob IDE is the core environment and the showcase (Agent mode, parallel subagents, document understanding). Judges must see Bob as the engine.

## Not BGI a2a-omega
Different product, different repo, different demo. A2A stays on BGI. Optional transport glue is not the headline.
